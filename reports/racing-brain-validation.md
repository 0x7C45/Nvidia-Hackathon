# 赛车内嵌脑观察验证

2026-09-13，本机完整 MaleCNS v1.0。保留 166,700 个神经元、25,582,938 条连接、全部已存位置与 114 个官方脑区外形，未修改上游源码、图拓扑或原生权重。

## 显示与操作

右侧使用原神经观察室的同一个 `BrainView` 类，保留原来的五组脑区颜色、神经点云、外形、只看激活、旋转／缩放、细胞点选与完整骨架入口。赛车用独立 `BrainMonitor` 管理显示与订阅，不创建另一个原生模拟器。

浏览器已验证：完整位置 166,700 个，外形合批数为 3；鼠标拖动使相机从正面位置 `[30.54,13.99,1699.88]` 旋转到 `[-1057.27,1309.03,-53.46]`；滚轮可缩放；只看激活及脑区开关能改变显示。隐藏视叶后基础绘制调用由 4 降为 3，数据中的真实放电计数不受显示过滤影响。

随车观察保留赛车自己的控制方式。选中果蝇 02 后，旧观察 session 释放，新 session 绑定车 ID 1，神经时间重置为 0，比赛世界保留原状态。原生驾驶模式仍独立保留；其显示隐藏不释放驾驶控制权。

## 真实感觉输入的数值对照

每个条件从相同原生初态开始，推进 100 ms，视觉条件使用 64×32、亮度 0.3 的图像。所有 ID 均由官方注释解析，详见 `racing-sensory-validation.json`。

| 条件 | 对应输入细胞的实际脉冲数 | 全图激活神经元 |
| --- | ---: | ---: |
| 暗场（保留既定 lamina bias） | 视网膜 0 | 8,634 |
| 仅图像 | 视网膜 40,020 | 9,876 |
| 图像＋躯体 | 左侧 25、右侧 31 | 12,938 |
| 图像＋氮气 | 490 | 12,664 |
| 图像＋触碰 | 72 | 13,464 |
| 图像＋奖励糖刺激 | 286 | 15,219 |

图像基线中，新增身体、氮气、触碰和糖感觉目标组的脉冲数均为 0；显式加入各输入后，对应目标组实际产生放电。每种条件的完整权重数组均与初始数组逐元素相同。直接调用 `reward` 前后的电位数组也相同；神经响应只由后续显式 observation 引起。

这是一套工程反馈映射，不把赛车氮气解释成真实果蝇的天然感觉，也不将神经激活当作权重学习。

## 性能和暂停

- 脑点云 1 次绘制、脑区外形 3 次绘制，完整结构基础共 4 draw calls；选中的骨架与标记按需增加。
- 赛车脑画布像素比上限为 1.25，绘制上限为 30 FPS。新神经窗口与镜头操作才请求重绘，实际活动更新频率服从原生计算速度。
- 收起后的两次检查，脑绘制帧数都为 **154**，订阅已关闭，观察 session 已释放；见 `racing-brain-hidden.json`。
- 滚出右侧可见区域时，脑视图停止绘制并关闭显示订阅；其加载好的位置、外形留在内存，重新展开不重复下载。切换对象后的会话与观察来源记录见 `racing-brain-switched.json`。
- 赛车车载镜头按右侧滚动容器裁剪，离屏时跳过该显示 pass 和预览像素读回；真正的原生相机输入仍照常生成。
- 一次完整运行中的赛车渲染采样约 53 FPS；较活跃的完整原生模型本次可慢至约 0.11×。图形绘制优化不会把真实神经时间伪装成墙钟实时，界面同时显示实际倍率和神经时间。
