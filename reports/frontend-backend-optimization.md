# 本地网页与运行性能优化

2026-09-13，Apple M4 / 16 GB MacBook Air。运行地址：http://127.0.0.1:8787/。

界面已重做，后端采用无损传输与更少的数据整理。全亮场短时对照中，完整网络推进速度改善约 **2%**；传输量和渲染空转开销的改善更明显。原生神经计算仍占主要时间。

## 界面与操作

- 深色实验台布局，大幅三维视图；左侧以「刺激 / 脑区 / 细胞」组织操作，底部固定暂停、继续和重置。
- 统一字型、图标、色彩和间距。解剖分区使用语义颜色，活跃点的亮度来自实际放电计数。
- 相机平滑切换，拖动带阻尼，提供完整系统、脑部、腹神经索视角及全屏；尊重系统减少动态效果设置。
- 活跃细胞列表可直接点选。单细胞面板显示放电、电位、官方定位类型和完整骨架，可一键聚焦分支。
- 活动曲线、模拟时钟和速度集中在视图下方；重置清空旧曲线，暂停时不显示过时的推进速度。
- 暂停且相机静止时停止重绘；隐藏页面断开放电订阅，无观看者时暂停计算。重新查看自动连接。

实际检查通过了视角切换、鼠标拖动、运行与暂停、细胞列表选择及骨架聚焦。例如 Dm19 / body 10430 成功显示 **5,226 条官方骨架分支段**。

## 同机前后对照

四轮串行全亮场测试，顺序为旧、新、新、旧；每轮从相同初态推进 5 个模拟秒。被测工作线程没有连接浏览器，另一个网页服务保持暂停。只存在一个正在计算的神经工作线程。表中为每版本两轮均值。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 5 个模拟秒所需真实时间 | 4.093 s | 4.014 s |
| 模拟秒 / 真实秒 | 1.222× | 1.246× |
| 每个观察窗口的数据整理耗时 | 2.501 ms | 0.791 ms |
| 同一最终窗口的二进制包 | 333,424 B | 55,012 B |

整体提速 **1.98%**，数据整理耗时减少 **68.36%**，该窗口传输体积减少 **83.50%**。传输量会随活跃细胞数变化；高密度放电时自动使用稠密格式。这些包大小未计 WebSocket 帧头与状态 JSON。

另一次浏览器实测同时开启完整网络、脉冲刺激和三维自动旋转：当时有两个页面订阅同一个模型。四个连续样本中，持续旋转页面约 **60 FPS**，另一页面按数据更新约 **12 FPS**；神经推进速度约 **1.23×**。画面帧率和神经时间推进速度是不同指标；结果见 `render-live-validation.json`。

继续运行至约 175–177 个模拟秒时，又观察到 **0.66–0.68×**，当时有两个观看页面，相机静止。证据见 `render-late-observation.json`。本次没有隔离出该下降由活动状态、温度或系统争用中的哪一项导致，因此不把它归因于某个未测量因素，也不承诺持续实时。

以上是短时受控测量，不能据此认定长时间运行恒定超过实时速度。此前十分钟无网页基准为 **0.96085×**，详见 `local-readiness.md`。两类测量的负载与持续时间不同，不能用其差值当作此次提速。

原始记录：`runtime-optimization.json`；复现记录中的脚本为 `optimization-source/measure_runtime.py`，旧后端快照为 `optimization-source/web_server_before.py`。执行前暂停当前网页，避免同时计算；使用项目 Python 环境及 `PYTHONPATH=scripts:vendor/doomfly`，固定单线程 BLAS。记录中的 RSS 来自同一个串行测量进程，不作为版本间内存峰值对照。

## 实际采用的优化

1. 放电信号改用 FLY2：传输活跃细胞索引和计数，静默细胞为隐式零。稀疏表示更大时，回退到全量计数。每个观察窗口仍可还原所有 166,700 个值。
2. 脑区统计从反复扫描全体细胞改为按活跃索引累计；数据整理移出共享锁的大部分区域。
3. WebSocket 改为收到新状态即唤醒发送，取消固定 50 ms 轮询；小型二进制包不再额外压缩。
4. 114 个原始分区外形合并成 3 个显示批次，全体位置使用一次点绘制。浏览器实测普通视图为 **4 次绘制调用 / 帧**；选中骨架和标记会增加调用。
5. 画面按需更新，不把模拟更新频率当作浏览器性能上限。暂停静止的 3.2 秒检查中，绘制计数保持 **7 → 7**，新增绘制为零。

神经元、连接、权重、0.1 ms 神经步长与固定 LIF 动力学保持原样。曾尝试两个跳过精确静息状态计算的内核改动，虽然数值一致，但活跃刺激下反而慢约 3%–8%，均未采用。上游源码没有修改。

## 正确性与构建

- 前端类型检查与生产构建通过；Ruff、严格 Mypy 通过。
- 15 项本地网页测试通过，覆盖稀疏/稠密编码、静默细胞、计数范围、错误索引、输入约束和全图定位对应关系。
- 优化前后四轮最终逐神经元放电、电位、突触状态与脑区统计完全一致。
- 对实际 WebSocket 连续 5 个 100 ms 窗口，共 **833,500 个逐细胞计数**，与新的完整原生模型对照，全部一致；重置归零、暂停冻结也通过。

证据：`web-tests.log`、`web-signal-validation-v2.json`、`render-idle-validation.json`、`render-motion-validation.json`、`logs/redesign-build.log`。网页提供本地只读 `/api/performance`，查看当时的模拟速度与浏览器实际绘制计数。

本次重点是减少显示、传输和统计开销。要让完整神经模型的计算本身出现数倍提速，还需要新的计算内核与独立数值验证；本次没有靠删神经元、裁剪连接或增大神经时间步长换取速度。
